# Capacity server continuation (proposal)

A verified capacity wrapper derives one schema-4 `capacity_server` job. The
selected `-I -S -B` Python verifies installation and startup/imports in the same
process before entering the fixed RA server; no caller command or extra flags.
The inherited listening IPv4 loopback descriptor, device/inode/address, live
parent, native spec, staged instruments and complete tool inventory are pinned.
Linux parent-death bootstrap evidence is checked before any driver and on return.

Native evidence must identify that server PID. After all three drivers drain,
the existing close-trace route stops the native engine and flushes its traces.
Only then can the fixed shutdown route set Uvicorn's normal exit flag. Its
acknowledgment must name the owned child and parent. The existing final-point
budget includes shutdown and post-return verification; the 600-second retrieval
reserve stays intact. A reaped zero exit and absent owned group are required.

The child binds its normal return, closed engine thread and retained trace hashes;
the worker rechecks payload/import/environment/tool bytes afterwards. The parent
joins manifest/spec, handoff, worker, lifecycle, PID, trace closure and byte hashes.
Failed or missing joins refuse; error cleanup retains original failures, including
kill-wait/probe errors. Plain invocation remains explicitly unverified.

`server_startup_verified` describes only this joined component. Overall nested,
GPU, native-context absence and release clearance remain false. The loopback
endpoint is not authentication against another local process. The advisory RA
lock, arbitrary descendants, GPU contexts, ABBA/source/input/default/telemetry
integration and provider/ledger/launch/teardown gates remain separate work.

CPU controls use tiny synthetic wheels/shim and substituted server bodies. Darwin
refuses the native listening option; its fixture observes only socket identity.
The selected extracted Linux 3.11.13 control exercises the real option and rejects
a post-return path mutation. Neither proves real Uvicorn/SC2, real setuptools,
full-image/87-wheel installation, GPU engagement or proof clearance.
