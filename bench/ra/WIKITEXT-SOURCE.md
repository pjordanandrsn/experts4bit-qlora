# Reviewed WikiText raw archive binding

`ra_wikitext.py` is a standalone, no-site input proposal. The selected Python
`-I -S -B` gate binds the one `wikitext-2-raw-v1` test Parquet archive to a
reviewed dataset revision and repeated bounded Hub index responses. It imports
no release package and downloads no dataset payload.

The exact manifest fields are the existing input spec, reviewed whole lock SHA
and registered stage. Within the complete reviewed dataset tree, the fixed
`wikitext-authority.json` has exactly schema, repository, configuration, split,
full revision and filename. This file's bytes and the complete retained
`wikitext-2-raw-v1/test-00000-of-00001.parquet` bytes must appear in the lock.
The authority file is an independently reviewed input choice, not a new frozen
instrument pin. The repository/configuration/test split are also derived from
both registered staged P109 and P97 loader calls. Their original bytes stay
unchanged.

The gate fetches complete public info and recursive tree records twice, with
fixed HTTPS endpoints, bounded non-paged raw JSON, clock reads and the original
collector's proxy/redirect/duplicate-JSON refusals. It reconciles complete
file/directory sets, Git addresses, sizes and LFS identities, independently
derives canonical LFS pointer Git addresses, and requires exactly one named
test shard. It compares the retained test file's complete SHA and size to that
LFS record. Other repository payloads are indexed but are not materialized or
claimed to have been hashed locally.

The `PAR1` edges and footer length are envelope checks only. They do not parse
Parquet schema, pages or text. Before/after common input inventories, helper
bytes, stage and authority identities must agree. Failures retain completed
raw responses and a failed receipt when execution reached the output stage.
Output is fresh and cannot overlap protected sources/inputs/tools.

`proves_hub_index_raw_wikitext_equality` describes Hub-reported index and local
raw-byte equality only. Publisher signature, Parquet decoding, joined text,
tokenizer execution, model consumption, GPU engagement and launch authority
remain false. The frozen native dataset calls have no revision argument;
this proposal therefore explicitly leaves native loader revision binding
false. A reviewed offline decoding/loading adapter must bind the retained
archive and its decoded text before runtime consumption can be established.

This helper is not yet in the fixed 35-tool worker or ABBA inventory. Do not
discover or admit it as an extra helper. Any future expansion and invocation
must be explicit and reviewed. The baseline, battery, bounds and all19 frozen
instrument pins remain unchanged. No full-image installation, rental, GPU
proof or release clearance is requested.
