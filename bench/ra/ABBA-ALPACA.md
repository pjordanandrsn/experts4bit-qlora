# Fixed ABBA Alpaca source composition

Schema 5 adds exactly eight fixed selected-interpreter `-I -S -B` Alpaca
processes: before and after each `old_a,new_a,new_b,old_b` position. The
existing eight publication probes, eight checkpoint probes and 24 measured
wrapper phases remain. `alpaca_source` contains only `timeout_s`; the parent
derives its manifest from the reviewed common input lock, spec and stage.
There is no caller command, dataset choice, manifest override or extra flag.

The stage-verified registered builder supplies the literal source repository,
revision, filename, raw SHA, seed 3407 and 1200/48 split. The child verifies
the complete 51,760-row source hash and independently regenerates the complete
canonical UTF8 prepared bytes, including selected text and metadata. After
the guarded child is reaped with its process group absent, the parent joins
the PID, manifest hash, successful process and exact receipt inventory, then
rehashes and regenerates those source/projection bytes itself. A resealed
child summary cannot substitute for that parent evaluation. The pure `audit`
function supports the parent; the standalone execution entry still requires
`-I -S -B` through `verify`.

The complete common identity must match both sides of every position and
every repeated position. Failed gates retain their manifest, process log,
guard/process evidence, child receipt and the supervisor's active phase and
completed prefix. There is one attempt and no retry. All eight timeouts are
included in the total deadline with the existing 600-second retrieval reserve.
Outputs and advisory locks cannot overlap source, tool, archive, installation,
input or staged bytes. The advisory lock excludes cooperating RA only.

The worker inventory expands explicitly from 34 to 35 files, adding only
`ra_alpaca.py`. No tool discovery or unknown Python file is accepted. Earlier
worker and checkpoint PR bases retain their original inventories.

`registered_alpaca_source_verified` records this component's source/projection
equality only. Completion remains
`ORDERED_COMPONENTS_RECORDED_PENDING_GATES`. It does not establish WikiText or
calibration authority, tokenizer execution, actual model input consumption,
publisher signatures, GPU engagement, native context absence, launch authority
or release clearance. The executor and launch gates remain incomplete; this
library has no rental or launch CLI.

The focused tests use full-size synthetic source bytes and fixture-owned
narrowed recipe/pins. Selected extracted Linux CPython controls exercise the
real fixed guarded child and parent receipt joins in two copied venvs; unrelated
