Pre-registration for lane **p41**: [`P41-PREREG.md`](P41-PREREG.md), written 2026-09-06 05:08Z under issue [#433](https://github.com/pjordanandrsn/experts4bit-qlora/issues/433) in the form of `bench/h2h-20260906/tp2/P40-PREREG.md` and `bench/h2h-20260905/p37/PREREG.md`.

**Status: the R1 campaign is closed `FAIL / STOP-1`** — one `VOID class=engagement` anchor row and 18 `NOT_RUN` rows over 26 launch attempts; no arm was ever admitted (the Amendments in the pre-registration carry the history). This directory holds the pre-registration and the drivers. Rental administration is not public: a run's authorisation, its cost and its operational receipt are recorded outside this repository, and only curated evidence supporting a published claim is published here.

What P41 registers when it runs (three sub-lanes, one fixture lineage — P38's fixture as P40 generalised it):

- **p41a** — the seq ∈ {512, 1024, 2048} × rank ∈ {8, 16, 32} training sweep per family (qwen3, mixtral, granite, olmoe; gemma4 only if #426 has merged; gpt-oss REFUSED), e4b reference/fused arms everywhere, Unsloth where its tp2 anchor was VALID. The (512, 8) cell of each family is the tp2 cross-lane anchor (±10 % or STOP).
- **p41b** — one downstream-task instrument beside perplexity: greedy ROUGE-L on the 48 held-out clinical rows, with a permuted-weights positive control that must fire before any reading is quoted.
- **p41c** — the 32 GB capability-boundary fixture: the sweep's peak-VRAM columns plus a seq-4096 probe per family, registered as `.footprint`-style rows, never speed ratios.

Cost plan: five runs, ≈ 16 h wall, ≈ $17 estimated (≤ $24 predicted bound), $35 per-run cap. STOP rules, validity vocabulary, and the PP1–PP8 prediction set are in the pre-registration; a FAIL stays FAIL and predictions are never edited after the fact.

When the lane has run, this README is replaced by the receipt-bundle README (the tp2/p37 form) in the receipts PR — receipts and code/claims land separately.


## Drivers (R1 onward; e4b#433)

- `p41_run.sh` — the box-side lane script in tp2's proven form: e4b from PyPI at the shipped cut (versions recorded), helpers (`n9_datasets.py`, `ds_manifest.json`, `train_anchor.py`, `train_anchor_gate.py`) from the repository archive at a **commit** (`E4B_SRC_REF`, 40 hex; the default is tag v0.35.3 resolved to its commit), each file **sha256-verified against the pins in the script** before anything from it runs; the registered clinical fixture sha (`76fb9036…`, PREREG "Fixture") asserted against the manifest and the bytes; the train-anchor gate; the **registered box class** (`RTX 5090` × 1) refused if absent and the exact machine recorded (`box.json`: instance id, provider, GPU uuid / bus id / serial, hostname); tokenisation per seq via `bench/tp3/tp3_arm.py --prepare`; then the family's grid seq-ascending / rank-ascending with the (512, 8) anchor first, fused_attn4 (PRIMARY) then reference_attn4 per cell, `alpha = 2r`, `--expect-trainable = (r/8) × the tp2 anchor count`, `--attn-4bit 1`, one process / one JSON / one `perl alarm` per arm from the planning curve, stubs for every non-run, the seq-4096 p41c probe, `TP_DONE`. **Every arm's receipt passes `p41_admit.py admit`** (below) or is rewritten as a VOID row. The STOP state machine is explicit and on the box: STOP-1 (anchor ±10 % → the family's remaining cells NOT_RUN), STOP-2 (an OOM at a sweep cell ends the family's ascent at that seq; the probe still runs — an OOM is its product), STOP-3 (two VOIDs of one class in a family halt it), STOP-4 (actuals + the remaining cells at the **planning curve** — never the alarm sum — vs 1.5 × the run's **amended planning estimate** (`P41_PLAN_EST_USD`, set per run thread from the pre-registration's Amendments; the approval line `E4B_RENT_EST_USD` is the governance guard recorded beside it — two numbers, two jobs), the rate from the launcher's `E4B_RENT_USD_PER_HOUR` / `E4B_RENT_EST_USD` — mandatory, the run refuses without them), STOP-5 (80 % of the guard, counted from the guard's own start = `E4B_RENT_DEADLINE_EPOCH − E4B_RENT_WALLCLOCK_S`). Each stop writes `STOPn` and appends to `stop_state.json` (rule, family, reason, effect, clock-read). `p41_run.sh --plan` prints the arm plan without a box (the tests read it).
- `p41_admit.py` — the pre-registration's validity rules, executable and tested: `admit` checks a harness receipt for N = 60 steps done, the cell's token sha, the exact trainable count, the structural attn-4bit census, engagement (fused: `n_patched == n_layers`, `kernel_calls_per_step_min ≥ 2·n_layers`) and C1 bit-exact; a failure rewrites the receipt as `status: void` (`status_harness`, `void_class`, `void_reason` kept; the measurement stays in the row and never enters a reading); the harness's own rows (oom / refused / alarm / …) are left as written; a harness VOID (`void_trainable`, `void_attn4`, `tokens_mismatch`, `c1_failed`) gets its class named for STOP-3. `footprint` turns the p41c probe's receipt plus the lane's nvidia-smi sampler into the family's footprint row (`fit_status` in P40's vocabulary, allocator peak, nvidia-smi max, seq / batch / offload design / checkpointing mode) — fit, never speed.
- `p41_drive.sh` — the controller-side `rent.py --command`: reads the box and the approval line from the launcher's `E4B_RENT_*` environment (e4b#464/#465: ssh endpoint, instance id, run dir, run id, deadline, rate ceiling, estimate) and refuses without any of them (rc 78); stages the harness, the lane script and the admission rules; starts the lane detached; polls `TP_DONE` while the launcher keeps the heartbeat fresh; rsyncs receipts / stubs / logs / forensics / versions / `box.json` / `stop_state.json` / the footprint row into the run directory and prints the admitted / VOID / stub counts. Exit 0 = the lane finished; anything else is HARNESS_ERROR in the receipt. It never creates, approves or tears down compute.
- The lane's own output (arm receipts, stubs, logs, forensics, versions, `box.json`, `stop_state.json`, the footprint row) is collected into the run directory the launcher hands it. The reducer and any resulting claim come in a receipts PR, carrying only the evidence a published claim rests on.
