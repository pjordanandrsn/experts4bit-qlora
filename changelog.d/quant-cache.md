### Added

- `E4B_QUANT_CACHE=DIR` (opt-in, default off and byte for byte unchanged): `load_moe_4bit_streaming(..., offload=True)` writes each MoE layer's packed 4-bit experts to `DIR/<key>/` on the first load and reads them back on later loads with the same key -- the checkpoint identity, the per-layer scheme, the dtype, the layout, the bitsandbytes and torch versions and `QUANT_FORMAT_VERSION` (pinned by a test against the quantizer's source). Safetensors and a JSON manifest only, every file sha256-checked on a hit (a mismatch refuses unless `E4B_QUANT_CACHE_REBUILD=1`), homes built by the same code as a fresh load, a hit on another GPU re-quantizes one layer and compares, concurrent writers resolve to one copy. `ExpertsNbit.from_packed` rebuilds a stack from its packed tensors. No load-time gain is claimed.
