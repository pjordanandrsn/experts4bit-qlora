### Claims register: a rented host's machine id stays only where a reading depends on it

`docs/claims.json` named the rented Vast machine in 115 places across 98 claims. Under the 2026-10-19 rule (keep a
provider machine id only where the reading or a registered amendment depends on it), 70 decorative mentions in host
descriptions were dropped from 67 claims. 45 stay:
- second-host replications and same-host comparisons;
- a result attributed to its host;
- every host a registration excludes or pins, or the host registry curates.

Only `hardware`, `notes` and `claim` text changed, and each changed string is its old text with exactly those
machine-id fragments removed. Every value, id, status, tier and evidence entry is unchanged. The census fixture's
offer id stays as a test source, and the completeness test's allowance for it now says so.
